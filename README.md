# NovaGram

**Telegram, который защищает не только переписку, но и устройство.**

Мессенджеры хорошо шифруют то, что летит по проводу. Гораздо хуже — то, что остаётся
на диске: история за годы, ключи входа в аккаунт, кэш, имена присланных файлов. Если
ноутбук или телефон попадёт в чужие руки — вместе с владельцем или без него, — вся эта
информация окажется доступна.

NovaGram — форк официальных клиентов Telegram для Windows и Android, который занимается
именно этим слоем. Протокол, серверы и сама переписка остаются телеграмовскими; меняется
то, что клиент хранит у вас, показывает на экране и рассказывает о себе по своей
инициативе.

## Что он делает

### Если устройство отобрали и требуют разблокировать

**Аварийный PIN.** Второй PIN, который вы задаёте рядом с обычным. Введённый на экране
блокировки, он не открывает приложение, а выходит из всех аккаунтов, удаляет локальные
данные и включает режим заглушки. Ни предупреждения, ни подтверждения — со стороны это
выглядит как обычная разблокировка.

**Синхронная деавторизация.** Аварийный PIN уничтожает то устройство, на котором его
ввели, — а аккаунт остаётся жить на планшете и на втором телефоне со всей перепиской.
Поэтому перед уничтожением устройство отправляет в «Избранное» короткий код и
дожидается подтверждения сервера, и только потом стирает себя. Остальные клиенты
NovaGram этого аккаунта видят код и делают у себя то же самое — даже если PIN на них
не задан. Включено по умолчанию.

**Режим заглушки.** После этого на экране обычный на вид Telegram: чаты, группы,
каналы, читаемые переписки, заполненные настройки приватности. Аккаунт при этом чужой,
а имя и номер телефона показываются ваши настоящие — иначе несовпадение с SIM-картой
выдало бы подмену сразу.

### Если украли сам файл с данными

В официальном Telegram папку с данными можно скопировать на другой компьютер или
телефон, и она откроется уже вошедшей в аккаунт. Ни облачного пароля, ни подтверждения,
ни уведомления о новом входе — для сервера это то же самое устройство.

**NovaGram запечатывает ключ входа ключом самой машины**, который вместе с файлами не
копируется: DPAPI и отпечаток компьютера на Windows, аппаратное хранилище ключей на
Android. Скопированная папка на другом устройстве просто не открывается. Работает даже
без PIN и включено по умолчанию.

**На Windows PIN шифрует локальные данные.** Из него выводится ключ, которым
перешифровывается локальный ключ Telegram — второй слой, уже против того, кто сидит за
этим же компьютером. Восстановления нет: забытый PIN означает потерю локальных данных.

### Каждый день, без вашего участия

| | |
| --- | --- |
| **Меньше следов на диске** | Свои сообщения удаляются по таймеру — и у вас, и у собеседника. Файлы сохраняются под обезличенными именами, чтобы папка загрузок не была списком присланного |
| **Меньше следов у собеседника** | В диалогах, начатых незнакомцем, не появляются галочки прочтения, пока вы не ответили сами |
| **Меньше данных в отправляемых файлах** | Из отправляемых JPEG и PNG вырезаются Exif, XMP и комментарии — то есть камера, время и координаты |
| **Экран не попадает в запись** | Окна клиента исключены из захвата экрана: программа для записи или демонстрации увидит пустой прямоугольник (Windows) |
| **DNS только по своему списку** | Имена, которые клиент разрешает сам, идут через пять закреплённых серверов — DNS-over-HTTPS, а для одного из них на Android DNS-over-TLS. Обращений к Google, Mozilla и Firebase, которые делает оригинал, не остаётся |
| **Звонок не выдаёт ваш IP** | Соединение всегда идёт через ретранслятор Telegram, и это решение принимает сам клиент, а не сервер |
| **Ничего лишнего о вас** | Телеметрия, отчёты о сбоях вырезаны из сборки |

Все настройки форка собраны в один раздел «NovaGram» с пояснением под каждым
переключателем.

## Чего он не делает

Это важнее списка возможностей.

- **Своего шифрования переписки нет.** Ни E2E поверх Telegram, ни скрытых чатов.
  Защищается устройство, а не канал связи.
- **Облачные данные не затрагиваются.** История на серверах Telegram, копии у
  собеседников и сессии на других устройствах остаются как были.
- **Уничтожение — это удаление, а не затирание.** Файлы пока не перезаписываются и
  восстанавливаются обычными средствами восстановления данных.
- **Метаданные чистятся у двух форматов** — JPEG и PNG. HEIC, PDF, документы Office,
  видео и теги аудио уходят как есть.
- **Рекламу форк не убирает.** Это осознанный отказ: убрать её нельзя, не нарушив
  условия Telegram API.
- **Push-уведомлений от Google нет** — сборки идут без сервисов Google, уведомления
  приходят по собственному соединению клиента.

Полный перечень границ, вплоть до слабостей оригинала, — в [документации](docs/NOVAGRAM.md#5-что-форк-не-делает).

## Как проверить, что здесь написана правда

Исходный код обеих платформ лежит в отдельных репозиториях, и каждый GitHub считает
форком официального клиента. Рабочие ветки отходят ровно от того официального тега, на
котором собран выпуск, и ничего из апстрима не теряют, поэтому разница открывается
одной ссылкой и читается построчно:

- **Windows:** [сравнение с Telegram Desktop `v7.2.8`](https://github.com/telegramdesktop/tdesktop/compare/v7.2.8...confeden:novagram-desktop:novagram/v7.0.7)
- **Android:** [сравнение с Telegram Android `12.10.1`](https://github.com/DrKLO/Telegram/compare/62b56a07...confeden:novagram-android:master)

Обе ссылки показывают текущее состояние — ровно тот код, из которого собран последний
выпуск: 178 изменённых файлов на ПК и 164 на Android, ни одного коммита апстрима позади.
Имя ветки на ПК осталось историческим, база у неё всё равно `v7.2.8`, и это видно в
самом сравнении.

**Чего эта проверка не даёт.** Она показывает исходный код, но не доказывает, что
файл в Releases собран именно из него. Воспроизводимой сборки у форка нет — собрать и
сверить самому остаётся единственным способом убедиться.

Обе базы обязаны быть последними официально опубликованными, и это не дисциплина, а
шлюз: проверка вызывается первой строкой каждой сборки и останавливает её, если
официальный клиент успел обновиться.

## Сборка из исходников

Требуются собственные `api_id`/`api_hash` Telegram — они читаются из локального файла
окружения и в репозиторий не попадают.

```powershell
.\scripts\build-desktop.ps1 -Config Release   # Windows
.\scripts\build-android.ps1                   # Android
```

Зафиксированные версии инструментов, ловушки сборки и подписывание —
в [документации](docs/NOVAGRAM.md#9-сборка).

## Лицензия и правовая информация

NovaGram — производная работа от официальных клиентов Telegram и распространяется на их
условиях: часть для Windows — **GNU GPL v3** с исключением для OpenSSL, часть для
Android — **GNU GPL v2**. Авторские права на исходный код Telegram принадлежат его
авторам.

NovaGram — независимый форк. Проект не связан с Telegram Messenger Inc., не одобрен ею
и не представляет её. Клиент работает с серверами Telegram и подчиняется их условиям
использования и Telegram API Terms of Service. Программа поставляется как есть, без
каких-либо гарантий.
