# NovaGram — форк Telegram с упором на приватность для Windows и Android

Форк Telegram, который защищает не переписку в канале связи, а само устройство:
что лежит на диске, что видно на экране, что клиент рассказывает о себе по своей
инициативе и что произойдёт, если телефон или ноутбук окажется в чужих руках вместе
с владельцем.

- **Аварийный PIN.** Второй PIN, который не разблокирует программу, а выходит из
  всех аккаунтов, удаляет локальные данные и включает заглушку. Со стороны
  неотличим от обычной разблокировки.
- **Режим заглушки.** После уничтожения на экране обычный на вид Telegram с чужим
  аккаунтом и читаемыми переписками — и настоящие имя и номер владельца, чтобы
  сошлось с SIM.
- **PIN шифрует `tdata` на ПК.** Из PIN выводится ключ, которым перешифровывается
  локальный ключ Telegram: скопированная папка на другом компьютере не открывается.
  Восстановления нет — забытый PIN означает потерю локальных данных.
- **Строгий DNS-over-HTTPS.** Апстримная цепочка Google → Mozilla → Firebase →
  системный резолвер заменена четырьмя зашитыми эндпоинтами. Касается имён, которые
  клиент разрешает сам: домен прокси, аварийный конфиг датацентров, сверка времени,
  проверка обновлений. WebView, внешний браузер и DNS самой ОС под это не попадают.
- **Окна не попадают в запись экрана** (Windows), **автоудаление своих сообщений**
  по таймеру, **скрытие квитанции о прочтении** в диалогах, начатых незнакомцем.
  Состояние каждой функции по платформам — в разделе ниже.

## Статус разработки

Ни одна функция не называется здесь работающей выше своего фактического
состояния. Полный разбор — что было в официальном Telegram, что сделал форк и
чего это **не** закрывает — в [`docs/features.md`](docs/features.md).

- `Проверено` — запущено на реальном аккаунте или устройстве и дало ожидаемый
  результат. Не «собралось», а именно прогнано руками.
- `Собрано` — код написан и собирается, запуском не проверено.
- `Основа` — хранилище и контракты готовы, функция не активна.
- `Ограничено` — платформа или Telegram API не дают сделать задуманное целиком.
- `Запланировано` — требования есть, кода нет.
- `Отклонено` — сделано не будет, причина названа.

Статусы ставит сопровождающий проекта, он же единственный, кто прогоняет
проверки: независимого аудита у форка нет.

| Что | Windows | Android |
| --- | --- | --- |
| Аварийный PIN, уничтожение данных, ядро заглушки | `Проверено`, на ПК — на холодном старте | `Проверено` |
| Обвязка PIN: момент запроса, задержка после ошибок, запрет биометрии, перемешанная клавиатура | `Собрано` | `Проверено`, кроме момента запроса |
| Наполнение заглушки: «Устройства», приватность, профили, участники групп | `Собрано` | `Собрано` |
| PIN шифрует локальные данные | `Проверено` | `Ограничено`: PIN — шлюз входа, база Telegram не шифруется |
| Строгий DNS-over-HTTPS | `Проверено` | `Проверено` |
| Автоудаление своих сообщений по таймеру | `Проверено` | `Собрано` |
| Ручная зачистка своих сообщений за период (`Erase evidence`) | `Собрано` | `Собрано` |
| Скрытие статуса прочтения | `Проверено`: гейт квитанции | `Собрано` |
| Запрет снимков и записи экрана | `Проверено` | `Основа` |
| Звонки только через ретранслятор — IP не виден собеседнику | `Проверено` | `Собрано` |
| Видимая система обновления | `Проверено` | `Собрано`; установку ведёт системный установщик APK |
| Серверу не отдаётся текст сообщения (`show_previews=false`) | `Собрано`, по умолчанию | `Собрано`, по умолчанию |
| Текст скрыт в самом уведомлении на экране | `Отклонено`: своего push нет | `Собрано`, по умолчанию |
| Отключение телеметрии, crash-отчётов и автообновления | `Собрано` | `Собрано` |
| Обезличенные имена файлов, очистка метаданных JPEG и PNG | `Собрано` | `Собрано` |
| Состояние PIN привязано к железу | `Запланировано` | `Проверено` |

**Чего форк не делает вовсе.** Своего шифрования переписки нет, протокол и
транспорт Telegram не тронуты — изменено только разрешение имён. Облачные данные и
копии у собеседников не затрагиваются, а уничтожение локальных данных — это
удаление, а не затирание диска. В выпускаемых сборках Android нет Google Services,
а значит и FCM: уведомления приходят по собственному соединению клиента и под Doze
могут задерживаться. Всё, что защищает NovaGram, находится на устройстве.

## Как проверить, что здесь написана правда

Исходный код обеих платформ лежит в отдельных репозиториях, и каждый из них GitHub
считает форком официального клиента — с пометкой «forked from» и кнопкой сравнения.
Ветки, на которых ведётся работа, отходят ровно от того официального тега, на
котором собран выпуск, и ничего из апстрима не теряют, поэтому разница открывается
одной ссылкой и читается построчно:

- **ПК:** [сравнение с Telegram Desktop `v7.0.9`](https://github.com/telegramdesktop/tdesktop/compare/v7.0.9...confeden:novagram-desktop:novagram/v7.0.7)
- **Android:** [сравнение с Telegram Android `12.9.2`](https://github.com/DrKLO/Telegram/compare/45ab8f43...confeden:novagram-android:master)

Обе ссылки показывают **текущее** состояние, то есть ровно тот код, из которого
собран последний выпуск `v7.0.9.3/12.9.2.3`: 116 изменённых файлов на ПК и 118 на
Android, ни одного коммита апстрима позади. Имя ветки на ПК осталось историческим
(`novagram/v7.0.7`) — база у неё всё равно `v7.0.9`, и это видно в самом сравнении.

Чего эта проверка не даёт: она показывает исходный код, а не то, что бинарник в
Releases собран именно из него. Воспроизводимой сборки у форка нет, собрать и
сверить самому — единственный способ убедиться.

## Привязка к оригиналу

Обе базы обязаны быть последними официально опубликованными, и это не дисциплина, а
шлюз: `scripts/check-upstream.ps1` вызывается первой строкой каждой сборки и
останавливает её, если апстрим новее. Сетевая проверка кэшируется на сутки,
принудительно — ключом `-Force`. Подробности в
[`UPSTREAM_POLICY.md`](UPSTREAM_POLICY.md).

Базы текущего выпуска: Telegram Desktop `v7.0.9` (Windows) и Telegram for Android
`12.9.2 (6991)`. Релиз один на обе платформы, и тег несёт обе базы:
`v<база ПК>/<база Android>`. Клиент сравнивает только свою половину.

## Сборка из исходников

Обе платформы требуют собственных `api_id`/`api_hash` Telegram — они читаются из
локального файла окружения и в репозиторий не попадают. Android собирается с
`minSdkVersion 23`; нативная часть строится с `ANDROID_PLATFORM=android-21`.

```powershell
.\scripts\build-desktop.ps1 -Config Release   # ПК
.\scripts\build-android.ps1                   # Android
.\scripts\check-upstream.ps1 -Project All -Force
```

Версии инструментов, ловушки сборки и подписывание — в [`docs/build.md`](docs/build.md).

## Лицензия и правовая информация

NovaGram — производная работа от официальных клиентов Telegram и распространяется на
их условиях: часть для ПК — **GNU GPL v3** с исключением для OpenSSL, часть для
Android — **GNU GPL v2**. Авторские права на исходный код Telegram принадлежат его
авторам.

NovaGram — независимый форк. Проект не связан с Telegram Messenger Inc., не одобрен
ею и не представляет её. Клиент работает с серверами Telegram и подчиняется их
условиям использования и Telegram API Terms of Service; сборка использует собственные
`api_id`/`api_hash`, и ответственность за их получение и соблюдение условий лежит на
том, кто собирает. Программа поставляется как есть, без каких-либо гарантий.
